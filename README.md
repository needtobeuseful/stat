# Сайт статистики игрока

Сайт для GitHub Pages: статистика игрока мини-игры за все его игры -
сколько он прошёл боксов, собрал сердечек, гладил котят, открыл сундуков
и т.д. - и ачивки, которые он уже получил. Сервера у сайта нет - это
статичные файлы, как и у редакторов комнаты и персонажа. Всё, что сайту
нужно знать об игроке, бот передаёт прямо в ссылке.

## Как это работает на стриме

1. Зритель пишет в чат `!статистика` (команда - `commands.stats` в
   `configs/minimap_game.yaml`; `""` - выключить). `!статистика ник` -
   статистика другого игрока.
2. Бот отвечает ссылкой на этот сайт. В ссылке после `#` - короткий код:
   ник, числа статистики и тексты полученных ачивок.
3. Сайт показывает всё это. Ссылка - снимок на день, когда её прислал бот:
   чтобы увидеть свежие числа, нужно попросить новую.

## Секретные ачивки

На самом сайте **нет списка ачивок**. Тексты есть только у тех ачивок,
которые игрок уже получил, - и только в его ссылке. Неполученные ачивки
сайт показывает одним числом («ещё 7»). Открыв сайт без ссылки, зритель
увидит только подсказку про команду.

В ссылке тексты ачивок идут не буквами, а номерами слов из словаря сайта -
`js/words.js` (так ссылка в несколько раз короче, см. ниже). В словаре
слова всех ачивок перемешаны с подставными - их в 10 раз больше: «сундук»,
«везунчик», «котолюб», «Светливка» и т.п. Целиком ни одного названия из
нескольких слов в словаре нет, и какие из слов настоящие, по нему не
понять. Отдельные слова при этом видны - поэтому лучше, чтобы
однословных названий ачивок было немного.

Тексты ачивок бот берёт из `achievements.list` в настройках, так что
переименовать ачивку можно в любой момент - сайт выкладывать заново не
нужно, новые ссылки сразу будут с новым текстом. Слова, которых нет в
словаре, бот отправляет буквами (ссылка чуть длиннее) и пишет об этом в
лог при запуске. Чтобы ссылка снова стала короткой, допишите эти слова
**в конец** словаря - лучше вместе с парой подставных - и выложите сайт
заново.

**Словарь только дописывают.** Не удаляйте, не меняйте и не переставляйте
в нём слова: номера слов уже разошлись в ссылках, и старые ссылки
показали бы чужие слова. Тесты бота это проверяют.

Ссылку можно подделать вручную (как и любую страницу без сервера), но ни
на что в игре это не влияет: настоящие данные игрока хранит бот.

## Короткая ссылка

Числа записаны битами (маленькие числа - 1-5 бит), ник из латиницы - по
6 бит на букву, а тексты ачивок - номерами слов из словаря: 10 бит на
слово, то есть около двух знаков ссылки. Слово не из словаря - кодом
Хаффмана по частотам русских букв (около 4,5 бит на букву). Ссылка игрока,
у которого все 31 ачивка, - около 280 знаков (буквами было бы 540, и тексты
пришлось бы обрезать). Если ачивок когда-нибудь станет очень много, бот
укоротит их тексты в ссылке, чтобы сообщение влезло в чат.

Ссылки, которые бот присылал раньше (тексты буквами), сайт читает как
прежде.

## Как выложить на GitHub Pages

Так же, как редакторы комнаты и персонажа:

1. Создайте **новый публичный** репозиторий, например `stats`.
2. **Add file → Upload files** и перетащите туда **содержимое** этой
   папки: `index.html`, `style.css`, `config.js`, `.nojekyll` и папку `js`.
   Нажмите **Commit changes**. Файл `.nojekyll` скрытый - если Проводник
   его не показывает, включите «Вид → Скрытые элементы».
3. **Settings → Pages**: Source - **Deploy from a branch**, Branch -
   **main**, папка **/ (root)**, **Save**.
4. Через минуту-две сайт откроется по адресу
   `https://<ваш-логин>.github.io/stats/`.
5. Впишите этот адрес в `configs/minimap_game.yaml` → `stats.site_url` и
   нажмите «Перечитать настройки» в окне мини-игры.

Обновить сайт - снова загрузить изменённые файлы с заменой.

## Как проверить у себя без GitHub

Пока бот запущен, он раздаёт этот сайт сам: на странице «Игроки» (окно
«Мини-игра» → кнопка с людьми) у каждого игрока есть кнопка «Статистика
игрока» - откроется его страница прямо у бота. Или двойной клик по
`start_local.bat` - откроется `http://localhost:8093/` (без ссылки -
только подсказка). Нужен установленный Python.

## Тексты - config.js

Заголовок, подписи и текст внизу страницы - в `config.js`. **Бот этот
файл не трогает** - правьте спокойно.

## Как устроено

```
index.html      страница
style.css       оформление
config.js       тексты - правятся руками
js/main.js      что показать: числа по разделам, ачивки
js/codec.js     код из ссылки - тот же кодек, что в боте (src/minimap/codes.py)
js/words.js     словарь: слова ачивок вперемешку с подставными - только дописывать
```
